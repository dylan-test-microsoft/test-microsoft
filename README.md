## Development

The repository currently has no build, runtime, or test dependencies. When adding code, include the relevant setup, usage, and validation commands in this README so future contributors can reproduce the workflow.

## Contributing notes

- Keep changes focused and easy to review.
- Document any new tools or external requirements alongside the code that needs them.
- Add tests or validation steps when introducing executable behavior.
