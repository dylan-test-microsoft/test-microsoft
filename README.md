# Test Microsoft

This repository is a lightweight test project used for validating GitHub and
Cursor workflow automation.

## Repository status

The project currently contains documentation only. There is no application
runtime, package manifest, or automated test suite checked in yet.

## Contents

- `README.md` - project overview and contribution notes

## Getting started

Clone the repository and review the tracked files:

```bash
git clone https://github.com/dylan-test-microsoft/test-microsoft.git
cd test-microsoft
```

No dependency installation is required for the current repository contents.

## Contributing

1. Create a branch for your change.
2. Keep changes focused and easy to review.
3. Update this README when repository behavior, setup, or structure changes.
4. Open a pull request against `main`.
